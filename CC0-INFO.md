## Current Project License
The project currently uses **MIT License** (see `LICENSE`).

To switch to CC0:
1. Replace `LICENSE` with CC0 content
2. Update `Cargo.toml` license field: `license = "CC0-1.0"`
3. Update README badges
4. Add CC0 headers to source files
