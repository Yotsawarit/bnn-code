# 🚀 BNN Code - Terminal-Native AI Coding Agent

Hi r/rust! I'm excited to announce that **BNN Code** is now accepting sponsorships 
to help sustain development and add new features.

## What is BNN Code?

BNN Code is a terminal-based AI coding assistant that helps you understand, 
refactor, and test your codebase using **Binarized Neural Networks (BNNs)**. 
It runs entirely in your terminal with zero IDE dependencies.

### Key Features:
- 🧠 **BNN Inference** - On-device AI with ONNX Runtime
- 🔍 **AST-aware Indexing** - Smart code understanding with tree-sitter
- 💾 **SQLite Backend** - Fast, local search and retrieval
- 🎯 **Multi-language Support** - Python, JavaScript, TypeScript, Rust, Go, Java, C++, Ruby, Swift, Kotlin
- ⚡ **Terminal-native UI** - Built with Ratatui + Crossterm

## Installation

```bash
cargo install bnn-code
```
