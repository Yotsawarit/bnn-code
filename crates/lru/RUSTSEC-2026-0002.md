# RUSTSEC-2026-0002

## Summary
LruCache::IterMut violates Stacked Borrows by invalidating internal pointers.

## Impact
Stacked Borrows violation -> undefined behavior, potential memory corruption in any project using lru 0.12.5 including bnn-code.

## Affected versions
0.12.5, 0.16.x

## Fixed versions
0.18.2

## References
- https://rustsec.org/advisories/RUSTSEC-2026-0002
- https://github.com/jeromefroe/lru-rs

## Fix
Update `lru` crate to `>=0.18.2` or update `bnn-code` dependency.

## Proof
From bnn-code: `cargo audit` before fix showed warnings for RUSTSEC-2026-0253 and RUSTSEC-2026-0002. After updating lru to 0.18.2, both warnings are resolved.
