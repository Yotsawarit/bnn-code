# GitHub Sponsors Setup Guide

## Step-by-Step: Enable GitHub Sponsors for Yotsawarit

### ✅ Step 1: Go to GitHub Sponsors Profile
**URL**: https://github.com/sponsors/Yotsawarit

### ✅ Step 2: Click "Set up your GitHub Sponsors profile"

### ✅ Step 3: Complete Your Profile
- **Profile Name**: Yotsawarit
- **Short Bio**: "Maintainer of BNN Code - Terminal AI Coding Agent"
- **Description**: 
  ```
  I'm building BNN Code, an open-source terminal-native AI coding assistant 
  powered by Binarized Neural Networks. Your support helps me maintain this 
  project and add new features for the Rust community.
  ```
- **Upload Profile Picture**: Use your GitHub avatar

### ✅ Step 4: Set Up Payment Method
You'll need to provide:
- Bank account info (for payouts)
- Tax information (W-9 for US, etc.)
- Billing address

### ✅ Step 5: Create Sponsorship Tiers

**Recommended Tiers:**

| Tier | Amount | Perks |
|------|--------|-------|
| **Supporter** | $3/month | Recognition as a sponsor |
| **Contributor** | $5/month | Sponsor badge + priority issue support |
| **Maintainer** | $10/month | Early access to features + Discord role |
| **Patron** | $50/month | Private consulting + feature requests |

**Tier Description Examples:**

**$3 - Supporter**
```
Help keep BNN Code free and open-source! Get your name in our sponsors list.
```

**$5 - Contributor**
```
• Your name in the README
• Priority support for issues
• Monthly updates on development progress
```

**$10 - Maintainer**
```
• Everything in Contributor +
• Early access to new features
• Private Discord channel for sponsors
• Direct support via email
```

**$50 - Patron**
```
• Everything in Maintainer +
• One-on-one consulting session per month
• Feature requests considered first
• Logo/name featured prominently in README
```

### ✅ Step 6: Activate Sponsors Profile
- Review terms
- Click "Activate sponsorship"
- Your sponsors page is now live!
